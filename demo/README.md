# ResearchTube bundled demo media

The release includes one generated, redistributable media file at the logical Agent Workspace path:

```text
demo/researchtube-demo.mp4
```

It contains an animated FFmpeg test pattern, a `ResearchTube Demo` label and a generated sine-wave audio track. It contains no personal, licensed or externally downloaded content.

The media exists to exercise:

- `media_probe`;
- batch frame extraction;
- visual maps;
- video clipping;
- full/partial audio extraction;
- inline image, video and audio display.

The authoritative ChatGPT sequence is [`docs/DEMO.md`](../docs/DEMO.md). The file must not be overwritten or deleted by an automated demo.
