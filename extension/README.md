## Development

```sh
npm ci
npm test
```

`background.js` and `youtube-page-bridge.src.js` are sources. `dist/background.js` and `youtube-page-bridge.js` are generated by the build and must not be edited as the only implementation.

Load this exact `extension/` directory with Chrome's **Load unpacked** action.
