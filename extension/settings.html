Start the Local Agent from your extracted ResearchTube release to enable Workspace and local media tools.

Silent file automation (optional)

This optional Chrome launch flag hides the debugging banner during browser automation.

On Windows, open your Chrome shortcut's Properties → Shortcut → Target and add this flag after the executable path:

--silent-debugger-extension-api

Exit Chrome completely, reopen it using that shortcut, then restart the Local Agent. On macOS/Linux, add the same flag to your Chrome launch command.
