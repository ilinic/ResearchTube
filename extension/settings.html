ResearchTube Settings

Connect this local Chrome extension to your OpenAI tunnel and ChatGPT.

1. Set up OpenAI connection

Create or choose an OpenAI tunnel and a separate Restricted OpenAI API Key. Both fields are required.

Use a Restricted OpenAI API Key with Tunnels: Read + Use permissions. Open OpenAI API Keys

Use the Tunnel ID from OpenAI Tunnels

2. Connect ChatGPT

Developer Mode is required to add a local Tunnel connection. Use a ChatGPT plan or workspace with Developer Mode access—typically Plus or higher.

  1. Open ChatGPT Settings and enable Developer Mode.
  2. Copy the Tunnel ID above.
  3. Open ChatGPT Plugins , then select the plus button to create a developer-mode app.
  4. Choose Tunnel under Connection, then select or paste the Tunnel ID.
  5. Name the app ResearchTube, then save it.

3. Try ResearchTube

@ResearchTube Search YouTube for recent videos about quantum computing. Read the relevant transcripts and summarize the main ideas.

Open a new ChatGPT chat and paste the example prompt.

Local Agent (optional)

The Local Agent prepares a private workspace for future local media features. It listens only on 127.0.0.1; YouTube research works normally when it is stopped.

Diagnostics

For troubleshooting only. The local log records concise tool timing, safe request summaries, errors, search queue state, and YouTube HTTP status. It never records OpenAI API keys, Tunnel IDs, YouTube cookies, request headers, response bodies, transcript text, or comment text.
