2. How to Set Up ResearchTube

Requirements: The latest version of Google Chrome and a paid ChatGPT subscription. ResearchTube is tested with ChatGPT Plus.

Step 1 — Create an OpenAI Tunnel

Open OpenAI Platform → Tunnels . Create a new tunnel or select an existing one. Use the Platform organization and ChatGPT workspace that should access it. Copy the tunnel_… ID. Creating a tunnel requires Tunnels: Read + Manage permission.

Step 2 — Create a restricted API key

Open OpenAI Platform → API Keys , create a Restricted key, and grant Tunnels: Read + Use. Copy the key when it appears. Never disclose it in a ChatGPT message, screenshot, or support request.

Step 3 — Connect ResearchTube to the tunnel

In 1. Set up OpenAI connection above, enter your API key and Tunnel ID, then click Save and test connection. Look for Connection successful. The API key stays in ResearchTube; do not enter it again in ChatGPT.

Step 4 — Enable ChatGPT Developer Mode

Open ChatGPT . Find Developer Mode under Settings → Apps → Advanced Settings (the location may vary). Enable it if your plan/workspace allows. In managed workspaces, an administrator may need to grant access.

Step 5 — Add ResearchTube as a custom MCP plugin

Visit ChatGPT Plugins , click + → Add custom MCP server. Name it ResearchTube. Under Connection, choose Tunnel and select or paste your Tunnel ID. Review any permissions/security prompts and create the plugin. ResearchTube must be connected while ChatGPT discovers tools.

Step 6 — Verify the connection

Start a new ChatGPT chat, select or mention @ResearchTube, and run the example under 3. Try ResearchTube. For local media tools, start the Local Agent and test it in Settings.

Troubleshooting: Check the Tunnel ID, key permissions, Platform organization/workspace association, and that ResearchTube is running. To update the tool list, select ResearchTube → Manage → Refresh in ChatGPT Plugins.

Silent file automation (optional)

To hide Chrome's debugging banner during ResearchTube automation, right-click your Chrome shortcut and open Properties → Shortcut → Target. Add a space and this flag at the end of Target:

--silent-debugger-extension-api

Exit Chrome completely, then reopen it using that shortcut.

Local Agent (optional)

The Local Agent prepares a private workspace for future local media features. It listens only on 127.0.0.1; YouTube research works normally when it is stopped.

Diagnostics

For troubleshooting only. The local log records concise tool timing, safe request summaries, errors, search queue state, and YouTube HTTP status. It never records OpenAI API keys, Tunnel IDs, YouTube cookies, request headers, response bodies, transcript text, or comment text.
