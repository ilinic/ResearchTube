How to Set Up ResearchTube

Requirements: The latest version of Google Chrome and a paid ChatGPT subscription. ResearchTube is tested with ChatGPT Plus.

Step 1 — Confirm the Chrome Extension is installed

Make sure you have completed these steps:

  • Download the ZIP for your operating system from Assets on GitHub Releases, not a Source code archive.
  • Extract the ZIP to a convenient place on your computer.
  • Open Chrome Extensions and enable Developer mode.
  • Click Load unpacked, select “ResearchTube/extension”, and check that the ResearchTube extension is loaded and enabled.
  • Keep the extracted ResearchTube folder in place. Do not move, rename or delete it.
  • Pin the extension to Chrome's toolbar.

Step 2 — Create an OpenAI Tunnel

Open OpenAI Platform → Tunnels . Create a new tunnel or select an existing one. Use the Platform organization and ChatGPT workspace that should access it. Copy the tunnel_… ID. Creating a tunnel requires Tunnels: Read + Manage permission.

Step 3 — Create a restricted API key

Open OpenAI Platform → API Keys , create a Restricted key, and grant Tunnels: Read + Use. Copy the key when it appears. Never disclose it in a ChatGPT message, screenshot, or support request.

Step 4 — Connect to OpenAI

In Set up OpenAI connection above, enter your API key and Tunnel ID, then click Save and test connection. Look for Connection successful. The API key stays in ResearchTube; do not enter it again in ChatGPT.

Step 5 — Start the Local Agent (optional)

Basic YouTube features work without the Local Agent. It adds downloads, local media, Workspace and Custom Tools. Start it before ChatGPT discovers the tools.

On Windows, open agent/ResearchTubeAgent.exe from the extracted release — no Python installation is needed. With Python installed, open a terminal in the agent folder and run “python researchtube_agent.py” (on macOS/Linux, use “python3 researchtube_agent.py”). Keep the Agent window open.

On the first launch, press Enter at the Workspace prompt to accept the default folder, or choose another folder. The Workspace can grow large, so choose a location on a drive with enough free space.

Use the same port as in agent/agent-config.json; the default is 17843. Click Test connection to check the Agent.

Step 6 — Enable Silent file automation (optional)

This optional Chrome launch flag hides the debugging banner during ResearchTube automation.

On Windows, right-click your Chrome shortcut and open Properties → Shortcut → Target. Keep the existing path and quotes; add a space and this flag after the closing quote:

--silent-debugger-extension-api

Click Apply, exit Chrome completely, then reopen it using that shortcut. On macOS/Linux, add the same flag to your Chrome launch command.

Restart the Local Agent to refresh its Chrome check. Open the ResearchTube popup and verify the OpenAI Tunnel is connected, Local Agent shows Ready, the Interface is compatible, and Silent file automation shows Enabled if you added the flag. Wait for any startup checks to finish.

Step 7 — Add ResearchTube as a custom MCP plugin

Before continuing, make sure the Local Agent is running and the ResearchTube Extension is enabled. Keep ResearchTube connected while ChatGPT discovers its tools.

Visit ChatGPT Plugins , click + → Add custom MCP server. Name it ResearchTube. Upload icons/researchtube-64.png from your extracted ResearchTube folder as the plugin icon. Under Connection, choose Tunnel and select or paste your Tunnel ID. Review any permissions/security prompts and create the plugin.

Step 8 — Try ResearchTube

Copy the example prompt below.

@ResearchTube Search YouTube for recent videos about quantum computing. Read the relevant transcripts and summarize the main ideas.

Open a new ChatGPT chat . Paste and send this prompt.

Step 9 — Troubleshooting

If something does not work, check the setup steps above and the connection statuses in the ResearchTube popup. Local Agent: Ready confirms that the Extension is connected to the Agent.

For questions or help, click Help in the ResearchTube popup. It opens a dedicated ChatGPT help chat where you can describe the problem and get setup or troubleshooting guidance in your language.

Diagnostics

For troubleshooting only. The local log records concise tool timing, safe request summaries, errors, search queue state, and YouTube HTTP status. It never records OpenAI API keys, Tunnel IDs, YouTube cookies, request headers, response bodies, transcript text, or comment text.
