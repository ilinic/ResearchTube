# ResearchTube MCP Tools

**Explore websites, understand YouTube videos and discussions, and turn local media into useful results — simply by asking ChatGPT.**

This catalog follows the tool groups, names and order in ResearchTube Settings. Each description explains what you can do; you do not need to learn commands or parameters. Tell ChatGPT the result you want, and it chooses the tools.

Browser-based YouTube research works without the Local Agent. Downloads, local files and media processing need it running. Clipboard tools and Windows speech voices require Windows; screen and camera capture depend on your system and permissions. You can choose which tools are available in Settings.

## System

Check that ResearchTube is ready before starting a task.

| Tool | What you can do |
| --- | --- |
| **Get ResearchTube Local Agent status** | Check whether the Local Agent is connected and compatible, and see the startup checks for your Workspace, media tools and Chrome. |

## Timers

Give ChatGPT a real countdown to check when your workflow needs a measured pause.

| Tool | What you can do |
| --- | --- |
| **Cancel a timer** | Stop a running countdown. |
| **Start a real timer** | Start a countdown for a chosen duration or until a specific time. |
| **Check timer progress** | See how much time has passed and how much remains. |

## Text to Speech

Listen to text aloud or turn it into an audio file.

| Tool | What you can do |
| --- | --- |
| **Cancel speech** | Stop an ongoing speech task. |
| **List Windows speech voices** | Discover the voices available on your Windows computer. |
| **Synthesize speech** | Read text aloud, save spoken audio, or do both using Google Translate or Windows speech. |
| **Get speech task status** | Follow speech generation, playback and any requested file delivery. |

## Workspace

Find and organize files in ResearchTube's local working folder.

| Tool | What you can do |
| --- | --- |
| **Delete a ResearchTube workspace item** | Delete a selected file or an empty folder. |
| **List a ResearchTube workspace directory** | Browse files and folders, optionally showing only selected file types. |
| **Create a ResearchTube workspace directory** | Create a folder to organize your research or media outputs. |
| **Move or rename a ResearchTube workspace item** | Rename a file or folder, or move it within your Workspace without replacing an existing item. |
| **Inspect a ResearchTube workspace file or directory** | Check an item's size, type and last modification time. |

## Browser Agent

Use **Study this site** in the extension popup to let ChatGPT explore a page through your browser, including content behind your login. It can read text, inspect images and interact with the page in that study session.

| Tool | What you can do |
| --- | --- |
| **Cancel site file task** | Stop an ongoing website download or pending delivery to chat, keeping files already saved. |
| **Site file task status** | Follow website downloads and see which files have been saved or sent to chat. |
| **Get site node children** | Explore the items inside a page section, such as a list, menu or form. |
| **Get site documents, audio and video** | Download documents, audio or video found on the page, and optionally send them to the study chat. |
| **Get site images** | Download selected page images so ChatGPT can inspect them, or save them locally. |
| **Inspect site node** | Examine a particular page element and discover its details or associated images and files. |
| **Read site node text** | Read the text of a selected section in more detail. |
| **Interact with site element** | Click controls, fill ordinary text fields, select options, hover, scroll and navigate the page. |
| **Read site page** | Read the page's content and structure, and discover available images and files. |
| **Site session status** | Check whether the website study session is active and which page it is studying. |
| **Stop site session** | End website automation while leaving the tabs and saved files in place. |

## Media and images

Inspect, capture, cut and convert media, then view or share the results in chat. Processing uses files on your computer; generated outputs are saved separately.

| Tool | What you can do |
| --- | --- |
| **Start frame extraction from workspace or YouTube** | Extract still images at chosen moments from a local video or supported YouTube video. |
| **Cancel frame extraction** | Stop extracting frames while keeping completed images. |
| **Get frame-extraction progress** | Track frame extraction and any requested delivery to chat. |
| **Get YouTube frame-extraction diagnostics** | Get information that helps explain why a YouTube frame could not be extracted. |
| **Capture desktop or screen region** | Save a screenshot of your desktop or a selected area. |
| **Cut and Convert Media** | Cut selected video or audio excerpts, convert a complete file to another format, or extract audio from video. Compatible tracks can be preserved without re-encoding. |
| **Cancel media clipping** | Stop a cut or conversion task while keeping completed outputs. |
| **Get media-clip progress** | Follow cutting or conversion and see the resulting files. |
| **Crop a workspace image** | Save a selected rectangular area of an image as a new picture. |
| **Inspect workspace image metadata** | Check an image's format, dimensions and file size. |
| **Inspect a workspace media file** | Discover a video's or audio file's duration, tracks, resolution, formats and other media details. |
| **Show workspace media in chat** | Display an image, video or audio player in chat for you to view or play. |
| **Cancel artifact task** | Stop an ongoing media creation task or its pending chat delivery, keeping files already saved. |
| **Check artifact task** | Follow a media task from creation through any requested delivery, and see progress and results. |
| **Send workspace files to the current chat** | Attach selected local files to your current conversation so ChatGPT can work with them. |
| **Cancel sending files to chat** | Stop a queued or ongoing file delivery before it is sent. |
| **Check sending files to chat** | Follow file attachment and submission, including any waiting period before sending. |

Viewing media in a player and giving it to ChatGPT for analysis are separate actions: ask to **attach the file** when you want ChatGPT to inspect its contents.

| Tool | What you can do |
| --- | --- |
| **Download a public YouTube video** | Download video, audio, or both, for the complete video or a selected time interval. |

## Clipboard

Bring copied text or images into your workflow, or copy a result for use in another application. These tools work on Windows.

| Tool | What you can do |
| --- | --- |
| **Read text or image from clipboard** | Read copied text or save a copied image in your Workspace. |

## Library and sharing

| Tool | What you can do |
| --- | --- |

| **Check a Library storage task** | See which files were submitted or skipped. ChatGPT handles their subsequent processing and Library availability. |

## Online Share

Create a temporary public link when you explicitly want to share local files outside your computer.

| Tool | What you can do |
| --- | --- |
| **Start an online share** | Share a selected Workspace file or selected file types from a folder through a temporary HTTPS link. |
| **Get online-share status** | Check whether sharing is active and optionally test whether a shared image can be reached online. |
| **Stop the online share** | Close the public link while keeping the local files. |
